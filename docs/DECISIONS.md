# DreamCart — Decision Log

## Confirmed

- Virtual shopping simulator, not a real marketplace.
- Real products with reference prices.
- No real transactions or physical deliveries.
- Web application first.
- High-quality UX/UI is a top priority.
- Low-cost MVP with strict scope control.
- Product Discovery feasibility must be validated.
- No complex AI features in the initial MVP.

## Proposed, Pending Approval

- Next.js and TypeScript
- Supabase PostgreSQL
- Vercel hosting
- Guest-first experience
- Modular Monolith architecture

## Critical Open Questions

- Legally usable product data sources
- Product image usage rights
- Initial curated catalog
- URL import strategy
- Data persistence and authentication
